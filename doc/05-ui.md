# 领星同步机 — UI 设计规范（宪法层）v2

> 5 个页面。店铺为中心，操作为主线。禁止引入 polabel2 那种多层导航和复杂操作动线。

---

## 1. 技术栈（无构建步骤，单二进制部署）

| 层 | 选型 | 说明 |
|---|---|---|
| 后端模板 | Go `html/template` | 服务端渲染 HTML shell |
| 样式 | Tailwind CSS CDN | `<script src="https://cdn.tailwindcss.com">` |
| 交互 | Alpine.js CDN | `<script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3/dist/cdn.min.js">` |
| 图标 | Heroicons SVG inline | 不引入 icon font，直接内联 SVG（16/20/24px） |
| 静态文件 | `//go:embed web/` | 打包进二进制 |

**禁止**：React / Vue / Webpack / npm / Node.js。服务器上只需要 Go 和 MySQL。

## 4. 页面一：API 配置（`/settings/api`）

### 目标：管理领星账号和已授权的店铺列表

```
API 配置                                     [+ 添加账号]

┌─── 账号：自营-美国（sc_us）─────────────────────────────────┐
│ App Key: abcd****efgh    状态: ● Token 有效（7200s）        │
│                          [测试连接]  [同步店铺]  [删除账号] │
│                                                             │
│ 已绑定店铺（3 个）：                                         │
│  店铺名         Seller ID    市场    状态                   │
│  美国自营店     A1B2C3...    US      ● 正常                 │
│  加拿大店       D4E5F6...    CA      ● 正常                 │
│  墨西哥店       G7H8I9...    MX      ⚠ 未同步              │
└─────────────────────────────────────────────────────────────┘

┌─── 账号：联营-欧洲（vc_eu）─────────────────────────────────┐
│ ...                                                         │
└─────────────────────────────────────────────────────────────┘
```

#### 按钮：+ 添加账号
- 位置：页面头部右侧
- 样式：primary 标准（`bg-blue-600 text-white px-4 py-2 rounded-lg text-sm`）
- 点击：展开内联表单（不跳页），填 app_key / app_secret / 名称 → 保存

#### 添加账号内联表单
```
名称     [________________]
App Key  [________________]
App Secret [______________]
         [取消]  [保存并测试]
```
"保存并测试"：先保存配置 → 自动调 `POST /api/settings/test-connection` → 成功显示绿色 toast，失败显示红色原始错误。

#### 按钮：测试连接（每账号一个）
- 样式：secondary 小号
- 点击：`POST /api/settings/test-connection?account=:id` → toast 结果（含延迟 ms）

#### 按钮：同步店铺（每账号一个）
- 样式：secondary 小号
- 作用：调领星"获取店铺列表"接口，更新已绑定店铺表
- 点击：spinner + "同步中…" → 完成后刷新店铺列表

#### 按钮：删除账号（每账号一个）
- 样式：`text-red-600 hover:underline text-sm`（ghost 链接式）
- 点击：**二次确认弹窗**："删除账号 sc_us 将停止所有关联同步任务，确认？" → 确认删除

## 5. 页面二：同步中心（`/`，首页）

### 目标：一眼看出"所有店铺 × 所有数据类型"的同步健康状态

```
同步中心

┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│店铺数 │ │今日成│ │今日错│ │最近同│
│  5   │ │功 48 │ │误  0 │ │3分前 │
└──────┘ └──────┘ └──────┘ └──────┘

状态矩阵（行 = 数据类型，列 = 店铺）：

           美国自营  加拿大  墨西哥  德国联营  法国联营
销售订单    ✓3m前   ✓8m前   ✗失败   ✓1h前   ✓45m前
FBA 库存    ✓1h前   ✓1h前   —      ✓2h前   ✓2h前
广告日报    ✓昨天   ✓昨天   —      ✓昨天   ⚪未启用
结算报告    ✓今天   ✓今天   —      ✓今天   ✓今天
```

矩阵单元格点击 → 跳到对应同步日志（带参数过滤）

单元格状态色：
- ✓ 成功（绿底白字 `bg-emerald-100 text-emerald-700`）
- ✗ 失败（红底 `bg-red-100 text-red-700`）
- ⚙ 运行中（蓝底 + 旋转图标）
- — 未配置（灰色斜线 `text-slate-300`）
- ⚪ 已禁用（灰底 `bg-slate-100 text-slate-400`）

## 6. 页面三：同步管理（`/sync`）

### 目标：手动触发 + 管理定时调度，同一页面，两个 Tab

```
同步管理
[手动同步]  [定时调度]      ← 两个 Tab，默认在"手动同步"
```

### Tab A：手动同步

```
┌─── 触发一次同步 ─────────────────────────────────────────────┐
│                                                              │
│ 数据类型   [销售订单 ▾]                                      │
│ 店铺       [美国自营店 ▾]  ☐ 全部店铺                       │
│ 日期范围   [2026-07-30] 至 [2026-08-06]   [近7天] [近30天]  │
│                                                              │
│                                    [立即同步]                │
└──────────────────────────────────────────────────────────────┘

正在运行（2 个）：
  ┌─────────────────────────────────────────────────┐
  │ 销售订单 / 美国自营  第 3/? 页   已写入 285 条  [取消] │
  │ FBA库存  / 加拿大    第 1/? 页   已写入 0 条   [取消] │
  └─────────────────────────────────────────────────┘
```

#### 按钮：立即同步
- 样式：primary 标准
- 禁用条件：未选数据类型 / 未选店铺 / 日期范围为空
- 点击：`POST /api/sync`（带参数）→ 任务出现在"正在运行"列表

#### 快捷日期按钮：近7天 / 近30天
- 样式：`text-xs text-blue-600 hover:underline px-1 cursor-pointer`
- 点击：填入对应日期范围

#### 按钮：取消（每个运行中任务）
- 样式：`text-xs text-red-600 hover:underline`
- 点击：二次确认 → `POST /api/sync/:id/cancel`

### Tab B：定时调度

```
数据类型        Cron 表达式        状态     上次执行     操作
销售订单        */10 * * * *       ● 启用   3 分钟前     [编辑] [禁用]
FBA 库存        0 */2 * * *        ● 启用   2 小时前     [编辑] [禁用]
广告日报        30 1 * * *         ● 启用   昨天 01:30   [编辑] [禁用]
结算报告        0 3 * * *          ○ 已禁用  —           [编辑] [启用]
```

#### 按钮：编辑（每行）
- 点击：弹出内联编辑行：`[cron 表达式输入框]  [保存] [取消]`
- Cron 输入框旁有提示：`*/10 * * * * = 每10分钟`

#### 按钮：禁用 / 启用（每行，状态切换）
- 禁用态→变灰；启用态→正常
- 点击直接切换，无需确认（非破坏性操作）

## 9. 通用组件规范

### 按钮（完整 Tailwind 类）

**Primary（主要操作）**
```html
<button class="inline-flex items-center gap-2 bg-blue-600 hover:bg-blue-700
  text-white text-sm font-medium px-4 py-2 rounded-lg transition-colors
  disabled:opacity-40 disabled:cursor-not-allowed">
```

**Secondary（次要操作）**
```html
<button class="inline-flex items-center gap-2 bg-white hover:bg-slate-50
  text-slate-700 text-sm font-medium px-4 py-2 rounded-lg border
  border-slate-200 transition-colors">
```

**小号 sm**：把 `px-4 py-2 text-sm` → `px-3 py-1.5 text-xs`

**Ghost/链接式（危险操作）**：`text-sm text-red-600 hover:underline cursor-pointer`

### 二次确认弹窗（全局，Alpine.js dispatch）

```html
<div x-data x-on:confirm-dialog.window="show($event.detail)"
     x-show="open" role="dialog" aria-modal="true"
     class="fixed inset-0 z-50 flex items-center justify-center bg-black/30">
  <div class="bg-white rounded-xl shadow-xl p-6 w-80">
    <p class="text-slate-800 text-sm mb-5" x-text="message"></p>
    <div class="flex gap-3 justify-end">
      <button @click="open=false" class="...secondary...">取消</button>
      <button @click="onConfirm(); open=false" class="...danger...">确认</button>
    </div>
  </div>
</div>
```

### Toast（右上角，自动消失）

```
[✓ 同步已触发]    ← green，3s 消失
[✗ 连接失败: …]   ← red，5s 消失，可手动关
[ℹ 配置已重载]    ← blue，3s 消失
```

`fixed top-4 right-4 z-50 flex flex-col gap-2`，每条 `w-72 bg-white border rounded-lg shadow-lg px-4 py-3 text-sm`

### 空状态

```
(图标)
暂无数据
(副文字，可选)
```

`py-16 text-center text-slate-400`，主图标48px，主文字 `text-slate-600 font-medium mt-2`

### 状态 Badge

| 状态 | 文字 | 样式 |
|---|---|---|
| 运行中 | 同步中 | `bg-blue-100 text-blue-700` + 旋转点 |
| 成功 | 成功 | `bg-emerald-100 text-emerald-700` |
| 失败 | 失败 | `bg-red-100 text-red-700` |
| 等待 | 等待 | `bg-slate-100 text-slate-500` |
| 禁用 | 已禁用 | `bg-slate-100 text-slate-400` |

基础类：`inline-flex items-center gap-1 px-2 py-0.5 rounded-full text-xs font-medium`
